# Skills roadmap

**Rule:** a skill only ships when it has real things to do and something else in the game needs what it produces. Empty skills are fake functionality.

XP curve: RuneScape's, unchanged (level 99 = 13,034,431 XP), continued to level 126 / 200M XP.
Pacing target with focused play: level 10 ≈ 20 min, 30 ≈ 4 h, 50 ≈ 25 h, 99 ≈ 400 h. One island only supports about level 15–20; more islands raise the ceiling.
