# Shattered Reef

Browser open-world pirate RPG (Three.js + TypeScript + Vite). First island: Bellwether Isle.

```bash
npm install
npm run dev        # play at http://localhost:5173
npm test           # game-rule tests (headless, ~2 s)
node scripts/e2e.cjs out/ --shots   # browser smoke test (needs dev server running)
npm run build      # static build in dist/ for GitHub Pages
```

See `PROJECT_LOG.md` for status, systems, controls and known issues, and `docs/ART_DIRECTION.md` for the look.
